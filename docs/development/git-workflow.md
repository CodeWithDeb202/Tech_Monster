# Git Workflow

## Purpose

This document defines the Git workflow for the Tech Monster project.

The goal is to keep development organized, changes traceable, branches focused, and collaboration safe as the project grows.

---

# Git Workflow Overview

```text
Create Issue / Task
        ↓
Update Local Repository
        ↓
Create Feature Branch
        ↓
Implement Changes
        ↓
Test Changes
        ↓
Commit Changes
        ↓
Push Branch
        ↓
Open Pull Request
        ↓
Code Review
        ↓
CI Checks
        ↓
Address Feedback
        ↓
Merge
        ↓
Delete Branch
