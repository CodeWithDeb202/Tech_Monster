# Tech Monster API Documentation

This directory contains the complete API documentation for the Tech Monster backend.

The API is implemented using Node.js, Express, and modular route architecture. All application API routes are registered from:

`backend/src/app.js`

The API documentation is organized by feature so that developers can quickly identify the correct endpoint documentation before working on or extending a module.
